# 李杜诗心 · 李白与杜甫诗句相似度可视化

用 23,448 组诗句配对，观察李白（1,084 首）与杜甫（1,462 首）两部诗集之间的语言关联。

![站点预览](assets/screenshot.png)

**在线访问**：<https://USERNAME.github.io/REPO/>（部署后把这里替换成你的地址）

---

## 这是什么

一个纯静态、零依赖的单页可视化网站：HTML + CSS + 原生 JavaScript，所有图表（直方图、累积曲线、散点、对数散点、二分网络）均由 Canvas 手绘，不加载任何 CDN 资源，断网也能打开。

五个部分：

| 视图 | 内容 |
| --- | --- |
| **总览** | 数据规模、两条「诗卷」与跨卷连线的主视觉、相似度直方图、四条阅读线索、最相似的六组诗句 |
| **相似度** | 拖动阈值（全部 / 中位数 / 前 10% / 前 5% / 前 1%），区间分布、累积曲线、双方覆盖、高分对排行 |
| **诗作网络** | 诗歌级二分网络：左李右杜，节点面积 ∝ 配对条目数；可切 60 / 120 / 200 / 全部，支持拖拽缩放、点选诗作查看配对对象 |
| **对照** | 句序位置散点、48 个共用字、诗长与配对数（对数坐标） |
| **检索** | 按诗句 / 诗题 / 关键字检索，可限定只找李白句或杜甫句、最低相似度、排序与分页 |

额外细节：纸 / 墨 / 夜三套主题、诗句与诗作详情弹层、深链接（`#network`）、`prefers-reduced-motion` 适配、900px / 560px 两级响应式。

## 数据说明

三份原始 CSV（`李白.csv`、`杜甫.csv`、`李白-杜甫.csv`）已一并放在仓库里，便于复现。

`李白-杜甫.csv` 没有表头，共 11 列，实际含义如下（经与两个诗人表逐行比对确认）：

| 列 | 含义 |
| --- | --- |
| 0–2 | 李白：诗人名 / 诗题 / 诗句 |
| 3–5 | 杜甫：诗人名 / 诗题 / 诗句 |
| 6 | **相似度**（0–10000，页面显示为 70.0–100.0） |
| 7 | 李白诗 ID |
| 8 | 李白句序（从 0 起） |
| 9 | 杜甫诗 ID |
| 10 | 杜甫句序（从 0 起） |

> 注意：最后四列是「李白 ID → 李白句序 → 杜甫 ID → 杜甫句序」，而不是先 ID 后句序的两组。
> 若把第 8 列当作杜甫句序，六成以上的句子会错配；本项目按上表解析后对全部 23,448 行做了原文回查，0 条缺失、0 条错位。

数据概况：

- 李白 1,084 首 / 14,469 行 / 91,767 字；杜甫 1,462 首 / 19,347 行 / 124,043 字
- 配对 23,448 组；相似度均值 73.2、中位数 72.3、前 1% 门槛 84.0、最高 100.0
- 李白 97.4%、杜甫 97.7% 的诗至少有一句进入配对
- 共同出现最多的字依次为「风」「不」「白」「人」「相」「酒」「天」「里」「水」「见」

重新生成数据（原始 CSV 更新后）：

```bash
python build_data.py
```

脚本会读取当前目录的三份 CSV，输出 `data.json` 与供页面直接引用的 `data.js`。

## 部署

仓库已包含 GitHub Pages 工作流：把代码推送到 `main` 分支后，在仓库的
**Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，
工作流会自动发布；之后每次推送都会自动更新。

也可以完全不使用 Actions：在 **Settings → Pages** 里选择 **Deploy from a branch**，
分支选 `main`、目录选 `/ (root)` 即可。
